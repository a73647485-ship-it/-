# FormaNest Studio

Публичная витрина карточек товаров и баннеров. Заказ продолжается в https://t.me/FormaNestStudio_bot. Сайт не принимает оплату и не сохраняет бриф на сервере. JavaScript готовит текст для ручной отправки в Telegram.

## Публикация в GitHub Pages

В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Дождитесь успешного Pages deployment. Адрес определяется настройками репозитория. Наличие файлов в GitHub само по себе не подтверждает публикацию сайта.

Для просмотра локально: Python 3.11+ → `python -m http.server 8020 --bind 127.0.0.1`, затем откройте http://127.0.0.1:8020. Сайт работает без сборки и внешних библиотек; относительные пути поддерживают project Pages.

## Состав

- index.html — витрина, портфолио, пакеты, процесс, FAQ, локальный помощник брифа.
- formanest.css — адаптивный интерфейс.
- formanest.js — увеличение макетов, выбор пакета, подготовка и копирование брифа.
- assets/card-1.png … card-3.png — неизменённые демоматериалы из предоставленного владельцем архива FN-6ED6855B.zip; это не клиентские кейсы.

Цена $200 на демонстрационных изображениях относится к условному товару, не к услуге студии. Прайс в Stars основан на сохранённом комплекте FormaNest от 21.10.2026; окончательные условия в боте. Техническая публикация витрины не подтверждает работу оплаты, возвратов или выплаты владельцу.

## Приватность

Нет аналитики, рекламных пикселей, внешних шрифтов или сторонних скриптов. Введённый бриф остаётся в открытой странице до закрытия/перезагрузки; копирование в буфер выполняется только по нажатию. При переходе в Telegram начинают действовать правила Telegram и бота. Фото загружаются непосредственно в бот. Не загружайте сюда .env, SQLite, клиентские данные или код с токенами.

## Автоматические заказы

Витрина не запускает отдельный обработчик Telegram и не перехватывает события существующего бота. Все кнопки ведут на обычную ссылку бота. Поддержка выбора пакета через start-параметр не предполагается без проверки действующего кода.
