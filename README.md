# Public website retired

The public FormaNest storefront has been closed at the owner's request.
Its root `index.html` is intentionally empty and does not link to a
Telegram bot, accept orders, or load scripts.

This repository was historically public. Retiring a landing page **does
not delete its Git history, cached pages, or Telegram messages**. To
prevent visitors from browsing source and assets directly, the repository
owner must also disable GitHub Pages and change the repository visibility
to Private in GitHub Settings (subject to account eligibility).

Bot shutdown and permanent deletion must be completed separately by
the bot owner through Telegram's official @BotFather. Do not publish
tokens, credentials, or customer databases here.
