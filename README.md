## Публикация в GitHub Pages

В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. Дождитесь успешного Pages deployment. Адрес определяется настройками репозитория. Наличие файлов в GitHub само по себе не подтверждает публикацию сайта.

Для просмотра локально: Python 3.11+ → `python -m http.server 8020 --bind 127.0.0.1`, затем откройте http://127.0.0.1:8020. Сайт работает без сборки и внешних библиотек; относительные пути поддерживают project Pages.

## Приватность

Нет аналитики, рекламных пикселей или внешних шрифтов. Для запрошенной интеграции загружается официальный SDK https://telegram.org/js/telegram-web-app.js. До нажатия отправки или перехода с заполненным черновиком введённый бриф остаётся в открытой странице; копирование в буфер выполняется только по нажатию. При переходе в Telegram начинают действовать правила Telegram и бота. Фото загружаются непосредственно в бот. Не загружайте сюда .env, SQLite, клиентские данные или код с токенами.

## Автоматические заказы

Витрина не запускает отдельный обработчик Telegram и не перехватывает события существующего бота. Все кнопки ведут на обычную ссылку бота. Поддержка выбора пакета через start-параметр не предполагается без проверки действующего кода.
